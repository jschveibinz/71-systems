# 71 Systems Website

This folder is ready for GitHub Pages. Upload `index.html`, `styles.css`, and `71systems-logo.png` to the root of a GitHub repository, then enable Pages in the repository settings using the main branch and root folder.

Before publishing, replace `info@71systems.com` in `index.html` if a different contact address should be used.

The `progiant/` directory publishes the PRO∙GIANT site at `https://www.71systems.com/progiant/`, including the owner, operations, and finance landing pages. Keep all PRO∙GIANT assets inside that directory so its relative links continue to work on GitHub Pages.
